Start of a lifelong romance: Dangerous Dave

The original DOS game by John Romero.

My first introduction to Computers. I used to play this game in our junior schools Computer Lab. Remove our shoes outside, huddle together on a Win95 system. I always found this game so fascinating, especially the sewer aesthetic, and the game sounds. So it makes sense to have a shrine to this game on my personal website, so that its always within reach.

Your browser needs canvas support to display the game.

Click the game screen to use the keyboard. Arrow keys move and jump; Ctrl fires; Alt uses the jetpack. Enter or Space advances the title screens. Tab leaves the game controls.
