# Dangerous Dave

**Game:** Dangerous Dave, by John Romero, published by Softdisk. This page runs the original DOS executable from the Gamer's Edge Sampler, including its game data and original notices. It is not a remake.

**Distribution:** https://www.dosgamesarchive.com/download/dangerous-dave/ identifies the sampler as freeware and states that the entire disk may be distributed provided its contents remain unaltered. This site retains the complete, unmodified `gameedge.zip` archive, including the original documentation and Catacomb files. DOSBox configuration is supplied separately; no original files are removed or changed.

**Archive SHA-256:** `5521f62645ccd6184804c24bc2f1e7ef605eb563ebf776f7f4373346865338c6`

**Download source:** https://www.dosgamesarchive.com/file.php?id=386

**Emulator:** js-dos `emulators` 8.5.3 / DOSBox (GPL-2.0). The license and corresponding source accompany the runtime in `vendor/`; see `vendor/SOURCES.md`.

**Controls:** Taken from the sampler's `DAVE.TXT`: arrow keys move/jump, Ctrl shoots, Alt activates the jetpack, F1 shows help, F2 opens the game control panel, F3 restarts from the title screen, F9 toggles the game's own pause, and F10/Escape quits. The page's Pause button suspends the emulator itself. The web UI provides Enter/Space buttons for title screens.

Progress is session-only. Restart reloads the original sampler; leaving the page stops the emulator. The page pauses when the browser loses focus or becomes hidden; select Resume to continue.
